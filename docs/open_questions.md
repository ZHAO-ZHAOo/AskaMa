## MVP 阶段说明

以上所有标注"需医生审核"的条目，在 MVP 阶段（黑客松原型）均无临床医生审核，以"权威来源引用"替代（每条医学内容必须引用公开权威来源，来源有分歧时取更保守的）。正式上线前仍需临床审核。

## 校验脚本实现中发现的 schema 缺陷或不一致

1. **`slots.yaml` 中 `usual_pain_relief_works` 槽位的枚举值 `yes`/`no` 被 YAML 1.1 解析为布尔值**：pyyaml 使用 YAML 1.1 规范，裸 `yes`/`no` 被解析为 `True`/`False`。建议将这两个值改为字符串引用（`"yes"`/`"no"`）或使用其他命名（如 `helped_yes`/`helped_no`）。校验脚本已做兼容处理（将 `True`/`False` 映射回 `yes`/`no`），但数据层面应修正。
2. **`facility.schema.json` 缺少 `last_verified` 和 `needs_verification` 字段**：校验脚本的 `last_verified` 过期检查和 `needs_verification` 检查无法在 facility 级别执行（当前只检查 meta 级别的 `last_verified`）。如果需要机构级别的验证信息跟踪，应考虑在 facility schema 中添加这些字段。
3. **`facility.schema.json` 中 `accepts_minors` 为 boolean 而非 enum**：任务描述提到 `accepts_adolescents` 为 `unknown` 时给 INFO，但 schema 中 `accepts_minors` 是 boolean，不支持 `unknown`。如果需要表示"不确定"，应改为 enum `[true, false, unknown]` 或增加单独的字段。
